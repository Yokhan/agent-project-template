# Design Guidance — Compatibility Entry Point

The maintained design workflow is
[domain-design-pipeline.md](../../library/domain/domain-design-pipeline.md).
Use [domain-design-system.md](../../library/domain/domain-design-system.md) for
new or substantially reworked systems, or the relevant existing-layer contract
for a focused change.

For concrete product, visual and game review failure modes, select the relevant
section of [design failure patterns](../../skills/domain-design-review/references/design-failure-patterns.md).
The [review skill](../../skills/domain-design-review/SKILL.md) owns review scope
and evidence. This compatibility path does not define a second pipeline.

Do not restore the former mandatory eight phases, per-component audit, numeric
design heuristics or universal bottom-up build order. Read only what the task
needs; preserve project visual direction, applicable accessibility standards,
rendered evidence and the shared Public Copy Gate.
